Project

Like everything here, this one started as plain markup. I write the HTML first and check that it still reads correctly with no CSS at all, then layer the design on top. It is a slower start, but it keeps the structure honest and the page usable when something fails to load.

What I took from it is in the parts nobody screenshots: the empty state, the loading state, and the layout at the width where it very nearly breaks. Those are what decide whether a project feels finished or merely done.
