About me

I'm a front-end developer learning the craft by building things end to end. Most of my time goes into HTML, CSS and JavaScript — written by hand rather than reached for through a framework, so that I actually understand what the browser is doing with them. I pick up PHP on the back end when a project calls for it.

This portfolio is one of those projects. Every interaction on the page is plain JavaScript: the navigation, the scroll animations, the counters, the image viewer. It adapts from a 320px phone to a wide desktop, follows your system's light or dark theme, can be driven entirely from the keyboard, and stays readable if the JavaScript never loads at all. Those constraints taught me more than the layout did.

The details I care about are the ones that are easy to skip: a tap target that is genuinely the size it looks, an image that doesn't shift the page as it loads, a form that tells you what's wrong before you submit it. I'd rather ship something small that works properly than something large that almost does. If you'd like to talk, the form below reaches me.

Services

What I can build today — and where I'm still getting better.

Web Design

I start from the content and let the layout follow, instead of pouring text into a grid I picked first. Most of my practice goes into spacing, type scale and the small decisions that make a page feel considered rather than assembled.

Web Development

Plain HTML, CSS and JavaScript, written by hand. Skipping the framework is slower at the start, but it means I can explain why every line is there — and fix it myself when the page misbehaves.

Accessibility

Keyboard paths, visible focus states, colour contrast and alt text that actually describes the image. Nearly all of it costs nothing while you build and a great deal to retrofit afterwards.

Responsive Design

One layout that holds from a 320px phone to a wide desktop, not a separate mobile site. I test the awkward widths in between, because that is where layouts actually break.

Performance

Compressed images in modern formats, nothing fetched before it is needed, and no layout shifting as the page settles. I measure on a mid-range phone rather than trusting how it feels on my laptop.

Version Control

Git for everything, including projects nobody else will ever touch. Small commits with messages that explain why, so the history is still worth reading six months later.
